Robby Roto · Web MAME

모바일 멀티터치 게임패드 · 브라우저 직접 실행

시작 대기

기존 FreeDOS VM의 DOS VGA 출력은 실제 게임 화면이 깨져 플레이에 적합하지 않았습니다. 이 페이지는 MAME 2003 Plus WebAssembly 코어로 게임을 직접 실행합니다. Robby Roto ROM은 권리자의 허가에 따라 MAMEdev가 공개한 비상업적 사용용 파일을 사용합니다.

ROM 사용 조건
화면을 가로로 돌리면 게임 화면과 가상 패드가 크게 표시됩니다. 기본 조작은 방향 패드, 버튼 1, COIN, START입니다.
